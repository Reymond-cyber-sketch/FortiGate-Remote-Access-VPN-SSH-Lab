MIKROTIK - ISP
==============

IDENTIDAD

Nombre del equipo:
ISP


FUNCION

Este MikroTik simula el proveedor de Internet entre:

- USER-ROUTER
- FGT-USER
- Nodo NAT de GNS3

Su función es enrutar el tráfico entre las redes públicas
utilizadas en el laboratorio y proporcionar salida a Internet.

SALIDA A INTERNET
=================

La interface ether10 obtiene una dirección IP mediante DHCP
desde el nodo NAT de GNS3.

Durante el laboratorio se utilizó una dirección de la red:

192.168.42.0/24

Gateway del nodo NAT:

192.168.42.1


NAT
===

El ISP utiliza NAT masquerade hacia la interface conectada
al nodo NAT de GNS3.

Interface de salida:

ether10

Acción:

masquerade

VPN REMOTE ACCESS
=================

El túnel VPN Remote Access se establece entre:

USER-PC

y

FGT-USER
198.51.100.98


El ISP solamente transporta el tráfico IPsec entre ambos extremos.

El túnel utiliza NAT-T debido a que USER-PC se encuentra
detrás del USER-ROUTER.

hacia el FortiGate.


COMANDOS PRINCIPALES UTILIZADOS
===============================

/ip address add address=198.51.100.97/30 \
interface=ether7 \
comment="WAN hacia FGT-USER"


/ip address add address=203.0.113.97/30 \
interface=ether8 \
comment="WAN hacia USER-ROUTER"


/ip dhcp-client add \
interface=ether10 \
add-default-route=yes \
use-peer-dns=yes \
disabled=no


/ip firewall nat add \
chain=srcnat \
out-interface=ether10 \
action=masquerade
